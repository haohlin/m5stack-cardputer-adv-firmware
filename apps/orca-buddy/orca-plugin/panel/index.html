Bridge setup

  1. Build desktop bridge from this repository.
  2. Initialize it with this Mac’s reachable LAN address.
  3. Install its per-user LaunchAgent.
  4. Configure Wi-Fi on Cardputer, then complete one USB serial pairing.

Full commands live in this plugin’s README. Plugin does not create, start, or configure the bridge.

Security boundary

Device pairing uses protected USB serial material, CA-validated WSS, and a dedicated bearer. This panel requests only workspace.readContext.
