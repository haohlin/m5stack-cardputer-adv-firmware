Bridge setup

  1. Open Orca’s Command Palette, run Orca Cardputer: Enable Bridge.
  2. Configure Wi-Fi on Cardputer, then attach its USB data cable.
  3. Run Orca Cardputer: Pair Connected Device.
  4. Disconnect USB; Cardputer reconnects over Wi-Fi.

Use Bridge Status, Device Diagnostics, or Disable Bridge from Command Palette. Device Diagnostics safely separates saved Wi-Fi, live Wi-Fi, saved pairing, and live bridge state without showing any secret.

Security boundary

Explicit commands run fixed local bridge and USB serial pairing helpers; no terminal text or pairing secret passes through panel. Device pairing uses protected USB serial material, CA-validated WSS, and a dedicated bearer. Plugin requests workspace.readContext and desktop notifications.
